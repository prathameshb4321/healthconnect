# HealthConnect

HealthConnect is a Flask-based Healthcare Support Web Application that allows patients to submit health concerns, automatically generates a patient summary, detects symptoms, and stores records in CSV format.

## Features

* Patient Support Form
* Automated Patient Summary
* Symptom Detection
* Automated Response Generation
* CSV Data Storage
* Flask Backend

## Tech Stack

* Python
* Flask
* HTML
* CSS

## Project Structure

healthconnect/
├── app.py
├── requirements.txt
├── templates/
├── static/
├── utils/
└── patients.csv

## Run Locally

1. Install dependencies

pip install -r requirements.txt

2. Run application

python app.py

3. Open browser

http://127.0.0.1:5000
